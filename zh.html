四柱
你出生的年、月、日、时，每一柱写成两个字，一共八个字。
天干与地支
十天干（甲 乙 丙 丁 戊 己 庚 辛 壬 癸）在上；十二地支（子 丑 寅 卯 辰 巳 午 未 申 酉 戌 亥），每支对应一个生肖，在下。
日主
日柱的天干。它代表你自己；命局的其他部分都是根据它来看的。
五行
木、火、土、金、水。每一行生下一行（木生火），也克另一行（水克火）。
十神
说明每个字与你的关系：比劫是与你同类的五行，食伤是你生出的，财是你克的，官杀是克你的，印是生你的。
旺衰与喜用神
日主强，适合用来泄耗它能量的五行；日主弱，适合用来生扶它的五行。
节气
八字的月份从节气开始（大约在每个公历月的4日到8日）。一年从立春开始，大约在2月4日。
大运
每十年一个阶段，影响人生的各个时期。当年的那一柱叫流年。

              GitHub
              这个 Claude 预览无法连接 GitHub，所以档案只存在这个浏览器里。在你的 GitHub Pages 版本上可以同步。

              档案会保存为一个文件，放在一个私有的 GitHub 仓库里。每台设备都需要同一个仓库和一个令牌。令牌只存在这个浏览器里。

              如何设置同步（只需一次）
              1. 在 GitHub 上新建一个私有仓库，例如bazi-data。保持为空。
              2. 进入 Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
              3. Repository access：Only select repositories → 选择bazi-data（只选这一个）。
              4. Permissions → Repository permissions → Contents: Read and write。其他都不要。
              5. 选择有效期（例如一年），生成，然后复制令牌。
              6. 在这里粘贴你的用户名、仓库名和令牌，然后点“连接”。每台设备都这样做。

              如果设备丢失，在 GitHub 上删除令牌，再新建一个。
