New to BaZi? The basics
Four pillars 四柱 · 八字
Your birth year, month, day and hour, each written as a pair of characters. Eight characters in all.
Stems and branches 天干 · 地支
Ten stems (甲 乙 丙 丁 戊 己 庚 辛 壬 癸) sit on top; twelve branches (子 丑 寅 卯 辰 巳 午 未 申 酉 戌 亥), one per animal, sit below.
Day Master 日主
The top character of the day pillar. It stands for you; the rest of the chart is read in relation to it.
Five elements 五行
Wood, Fire, Earth, Metal, Water. Each feeds the next (木生火) and controls another (水克火).
Ten gods 十神
Names for how each character relates to you: Peers 比劫 are your own element, Output 食伤 is what you produce, Wealth 财 is what you control, Officer 官杀 is what controls you, Resource 印 is what feeds you.
Strength and useful elements 旺衰 · 喜用神
A strong Day Master benefits from elements that use its energy; a weak one benefits from elements that add to it.
Solar terms 节气
BaZi months start on solar terms (around the 4th to 8th of each Western month). The year starts at Start of Spring 立春, around 4 February.
Luck pillars 大运 · 流年
Ten-year periods that colour each stage of life. The pillar for the current year is 流年.

                Sync across devices

                GitHub
                This Claude preview can't reach GitHub, so profiles stay in this browser. Sync works on your GitHub Pages copy of the app.

                Profiles are saved as one file in a private GitHub repo. Each device needs the same repo and a token. The token stays in this browser only.

                How to set up sync (once)
                1. On GitHub, create a new private repository, for example bazi-data. Leave it empty.
                2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
                3. Repository access: Only select repositories → pick bazi-data only.
                4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
                5. Choose an expiry (for example one year), generate, and copy the token.
                6. Paste your username, repo name and token here, then tap Connect. Do the same on each device.

                If a device is lost, delete the token on GitHub and make a new one.
